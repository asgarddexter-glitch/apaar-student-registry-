APAAR Student Registry

Student Data Management and Verification System · prototype for integration with the AICTE portal
Prototype built on synthetic data. No real student, institution or APAAR record is used. The APAAR checksum here is a stand-in (Verhoeff) because the production ID algorithm and registry API are issued by the APAAR authority. Signing keys are generated in your browser for demonstration; a deployment would hold them in an HSM.
